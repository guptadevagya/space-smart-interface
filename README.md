# OxNNet Economics

A simulation dashboard that shows the health and financial impact of using OxNNet AI screening to detect Fetal Growth Restriction (FGR) in pregnancy.

FGR affects about 8% of pregnancies. Current screening catches only 33% of cases. OxNNet catches 66% — and this tool shows what that difference means in lives saved, procedures avoided, and costs reduced.

Supports three markets: **US**, **UK**, and **Global**.

---

## Setup

1. Install [Node.js](https://nodejs.org) (LTS version)
2. Open a terminal in this project folder
3. Run:

```
npm install
npm run dev
```

4. Open **http://localhost:8080** in your browser

That's it. No internet needed after the first setup.

---

## Usage

- **Switch markets** using the tabs at the top (US / UK / Global)
- **Adjust parameters** in the left sidebar
- **Save scenarios** with the save icon in the header
- **Print reports** with the print icon
- **Stop the dashboard** by pressing `Ctrl + C` in the terminal
